## Theoretical Framework

| Resource | Description | License |
|----------|-------------|---------|
| **[The League of Digital Justice](/THEORY/league-of-digital-justice.pdf)** | Full theoretical framework (47 pages) | CC BY 4.0 |

The methodology beneath the tool. Introduces six cognitive archetypes for security practice:

| Archetype | Function | EIOC Application |
|-----------|----------|------------------|
| 🎭 **Storyteller Bard** | Narrative translation | Capacity assessment |
| 💚 **Compassionate Healer** | Psychological safety | Vulnerability diagnosis |
| 🔍 **Log Detective** | Pattern recognition | Behavioral deviation |
| 🛡️ **Guardian of Firewalls** | Boundary defense | Pressure detection |
| 🔮 **Strategic Oracle** | Risk forecasting | Trendline analysis |
| 🃏 **Trickster Hacker** | Adversarial testing | Exploit mapping |

Includes technical anchors (MITRE ATT&CK, Cialdini's influence principles, Zero Trust, FAIR), origin stories for each archetype, and integration guidance.

## Operational Tools

| Resource | Description | License |
|----------|-------------|---------|
| **[EIOC Incident Response Template](/OPERATIONS/eioc-ir-template.pdf)** | Six-mode IR methodology | CC BY 4.0 |
| **[Self-Assessment Quiz](/OPERATIONS/league-self-assessment-quiz.pdf)** | Practitioner archetype diagnostic | CC BY 4.0 |

### EIOC IR Template

A structured incident response template that operationalizes all six archetypes:

1. **Executive Summary** (Bard Mode) — Translate for leadership
2. **Timeline & Root Cause** (Detective Mode) — Reconstruct with precision
3. **Human Factors & EIOC Assessment** (Healer Mode) — Identify emotional vulnerabilities
4. **Boundary & Control Weaknesses** (Guardian Mode) — Map architectural gaps
5. **Future Risk Forecast** (Oracle Mode) — Project forward from patterns
6. **Adversarial Validation** (Trickster Mode) — Test findings through safe exploitation
7. **Remediation Plan** (Integrated League) — Holistic response

Includes a fully worked example: phishing-induced credential exposure analyzed through all six modes.

### Self-Assessment Quiz

30-question diagnostic for security practitioners to identify their dominant cognitive mode and growth edges. Scoring interpretation included.

**Why this model:**

The theoretical framework is open — enabling academic adoption, practitioner use, and industry credibility. The *implementation* (EIOC Guard) is proprietary — enabling sustainable development and enterprise licensing.

This mirrors established patterns: NIST frameworks are free; tools that implement them are commercial.
