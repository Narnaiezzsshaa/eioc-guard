## 🎯 What This Is

An interactive assessment tool that trains users to recognize **Emotional Indicators of Compromise (EIOCs)**—the psychological states attackers deliberately induce to bypass rational decision-making.

**[→ Try the Live Demo](https://narnaiezzsshaa.github.io/eioc-guard/eioc-guard-public-v1.5.html)**

### The Core Insight

Traditional training: *"Don't click suspicious links."*  
EIOC training: *"Recognize when urgency, authority, or empathy is being weaponized against you."*

## 📊 The EIOC Framework

Six emotional vulnerability categories mapped to technical exploit patterns:

| EIOC Category | Technical Mapping | Defensive Cue |
|---------------|-------------------|---------------|
| 🎭 Synthetic Familiarity | AI-Enhanced Trust Injection | *"Pause before you mirror."* |
| ⚡ Performance Reflex | Urgency Trigger Exploit | *"Urgency is not a credential."* |
| 💝 Empathic Camouflage | Affinity Bias Pretexting | *"Familiar warmth may conceal cold intent."* |
| 👔 Deference Drift | Authority Spoof Lever | *"Stewardship honors questions."* |
| 🎪 Prestige Mirage | Status-Based Exploit | *"Signal is earned, not borrowed."* |
| 📚 Duty Exploitation | Professional Obligation Lever | *"Care protects through process."* |
